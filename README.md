# Double Counter

## Overview
Discord Bot
## Installation
### Requirements
- Python 3.8+
- `disnake` library
- `python-dotenv`

### Setup
1. Clone the repository:
   ```sh
   git clone https://github.com/RareCreation/Double-Counter-CC.git
   cd Double-Counter
   ```
2. Install dependencies:
   ```sh
   pip install -r requirements.txt
   ```
3. Create a `.env` file in data and add your bot token:
   ```sh
   TOKEN=your-bot-token
   ```
4. Configure your bot settings in `config.py`:
   ```python
   ADMIN = [1234567890] 
   ```
5. Run the bot:
   ```sh
   python3 main.py
   ```
